Windows · Werkzeug im Infobereich

Korrigieren Sie Text im falschen Layout und sehen Sie das aktive Layout schon vor dem Tippen.

CyrFlip zeigt den Code des aktiven Tastaturlayouts direkt an der Schreibmarke und ersetzt vertippten Text, ohne ihn neu einzugeben.

Dieses Hintergrundprogramm für Windows zeigt das aktive Layout neben der Schreibmarke, installiert 13 verbreitete Sprachen und legt beliebig viele Umwandlungspaare zwischen den Layouts an, die Sie wählen.

ghbdtn→ Ctrl+Shift+F12 →привет
Microsoft Store GitHub Releases
winget install SerZhyAle.CyrFlip
  1. Aus dem Microsoft Store, per winget installieren oder das ZIP von GitHub Releases in einen dauerhaften Ordner entpacken.
  2. CyrFlip.exe starten und das Symbol im Infobereich suchen.
  3. Vertippten Text markieren und Strg+Umschalt+F12 drücken.

Layout vor dem Tippen sehen

Eine Markierung mit zwei Buchstaben erscheint an der Schreibmarke; die 13 kuratierten Sprachen haben eigene Farben, und CapsLock fügt einen Rahmen hinzu.

Bereits getippten Satz korrigieren

Markieren Sie Text wie ghbdtn und drücken Sie Strg+Umschalt+F12.

Versehentliches CapsLock beheben

Markieren Sie den Text und tauschen Sie GROSS-/Kleinschreibung mit einem eigenen, frei wählbaren Kürzel.

Eigene Layout-Paare

Eine Tabelle von Umwandlungen: beliebig viele Paare, jedes mit eigenem Kürzel und in beide Richtungen wirksam.

Schnellstart

Optional: Programme, Skripte und yt-dlp-Downloads als Szenarien starten — aus dem Infobereich, per eigenem Kürzel oder über die Sprungliste der Taskleiste. Standardmäßig ausgeschaltet.

Markierten Text übersetzen

Optional: Text markieren, Strg+Umschalt+F9 drücken — die Übersetzung erscheint in einem kleinen Fenster neben dem Mauszeiger und füllt sich, während sie entsteht. Sie läuft über Ollama, das Sie separat auf Ihrem eigenen Rechner installieren; standardmäßig ausgeschaltet.

Dasselbe - mit der Maus

Ein optionales eigenes Menü: Strg und ein Rechtsklick auf eine Auswahl öffnen direkt am Zeiger Kopieren, Layout-Umwandlung, Groß-/Kleinschreibung und Übersetzung. Die Auswahl bleibt dabei erhalten. Standardmäßig aus.

Wichtig zu wissen

Windows 10/11 x64 wird benötigt. Umgewandelt wird nach physischer Tastenposition; bereits zusammengesetzter IME-Text (etwa chinesisches Pinyin) bleibt unverändert. In Terminals und Apps mit eigener Schreibmarke kann die Markierung fehlen — Symbol im Infobereich und Mauszeiger zeigen das Layout trotzdem.
