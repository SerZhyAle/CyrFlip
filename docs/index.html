Нужны Windows 10/11 x64. Профили преобразуют однозначные символы по физическим клавишам; уже введённый IME-текст (например китайский Pinyin) оставляется без изменений.

Windows 10/11 x64 is required. Profiles convert unambiguous characters by physical key; already composed IME text (such as Chinese Pinyin) is left unchanged.

Потрібна Windows 10/11 x64. Профілі перетворюють однозначні символи за фізичними клавішами; уже введений IME-текст (наприклад китайський Pinyin) не змінюється.

Некоторые терминалы и приложения с собственной кареткой не сообщают её положение Windows — в них маркер у каретки может не появиться. В VS Code внешний оверлей может быть неточным; для точной метки в редакторе есть дополнительное расширение VS Code.

Some terminals and apps with a custom caret do not expose its position to Windows, so the caret marker may not appear there. In VS Code the external overlay can be imprecise; a companion VS Code extension provides an exact editor marker.

Деякі термінали й застосунки з власною кареткою не повідомляють її положення Windows, тому маркер біля каретки може там не з’явитися. У VS Code зовнішній оверлей може бути неточним; додаткове розширення VS Code дає точний маркер у редакторі.

Если принудительно завершить CyrFlip, системный I-beam может остаться изменённым до повторного запуска CyrFlip или нового входа в Windows. Не запускайте portable ZIP прямо из временной папки: сначала распакуйте его в постоянное место.

If CyrFlip is force-killed, the system I-beam can remain changed until CyrFlip runs again or you sign in again. Do not run the portable ZIP from a temporary folder: extract it to a permanent place first.

Якщо примусово завершити CyrFlip, системний I-beam може лишитися зміненим до повторного запуску CyrFlip або нового входу в Windows. Не запускайте portable ZIP із тимчасової папки: спершу розпакуйте його в постійне місце.

Для перевода нужны Ollama и языковая модель — это отдельная бесплатная загрузка на несколько гигабайт, которую вы делаете один раз. Качество перевода — это качество локальной модели, а первый перевод после запуска идёт дольше, пока модель загружается в память; память под модель занимает процесс Ollama, а не CyrFlip. Длинные выделения переводятся первыми 4000 символами, о чём окно сообщает.

Translation requires Ollama and a language model - a separate free download of several gigabytes that you make once. The quality is the quality of the local model, and the first translation after a cold start takes longer while the model loads; the memory for the model belongs to the Ollama process, not to CyrFlip. Of a long selection the first 4000 characters are translated, and the window says so.

Для перекладу потрібні Ollama та мовна модель — це окреме безкоштовне завантаження на кілька гігабайтів, яке ви робите один раз. Якість перекладу — це якість локальної моделі, а перший переклад після запуску триває довше, поки модель завантажується в пам’ять; пам’ять під модель займає процес Ollama, а не CyrFlip. Із довгого виділення перекладаються перші 4000 символів, і вікно про це повідомляє.

03Приватность, техническая информация и релизыPrivacy, technical information, and releasesПриватність, технічна інформація та релізи

Горячая клавиша использует глобальный хук клавиатуры; при перевороте выделения приложение временно использует буфер обмена и восстанавливает прежнее содержимое. Эти операции выполняются локально. Исходный код, лицензия MIT, полный privacy note и история изменений доступны по ссылкам ниже.

The hotkey uses a global keyboard hook; when flipping a selection, the app temporarily uses the clipboard and restores its previous contents. These operations happen locally. Source code, MIT licence, the full privacy note, and release history are available below.

Гаряча клавіша використовує глобальний хук клавіатури; під час перевороту виділення застосунок тимчасово використовує буфер обміну та відновлює попередній вміст. Ці операції виконуються локально. Вихідний код, ліцензія MIT, повний privacy note та історія релізів доступні за посиланнями нижче.

Пока перевод выключен, ни одного сетевого обращения не делается. Если его включить, выделенный текст уходит по сети на адрес Ollama из настроек: по умолчанию это http://localhost:11434 — ваш собственный компьютер, и текст его не покидает. Разработчику и в облачные сервисы не отправляется ничего; о том, что другой адрес означает отправку текста на тот компьютер, вкладка сообщает прямо.

While translation is off, no network connection is opened at all. If you enable it, the selected text is sent over the network to the Ollama address from the settings: by default that is http://localhost:11434 - your own computer, so the text never leaves it. Nothing is sent to the developer or to any cloud service, and the tab says plainly that another address means the text goes to that machine.

Поки переклад вимкнено, жодного мережевого звернення не робиться. Якщо його ввімкнути, виділений текст надсилається мережею на адресу Ollama з налаштувань: за замовчуванням це http://localhost:11434 — ваш власний комп’ютер, і текст його не покидає. Розробникові та у хмарні сервіси не надсилається нічого, а про те, що інша адреса означає надсилання тексту на той комп’ютер, вкладка повідомляє прямо.
