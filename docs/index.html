What it does

Typed a whole sentence before noticing the layout was wrong? Select it, press the hotkey, and CyrFlip transliterates it in place between QWERTY and ЙЦУКЕН (EN ↔ RU, with UK planned). It runs quietly in the background — its only UI is a custom mouse cursor showing the active layout (EN/RU/UK) in the corner.

How to use

  1. Run CyrFlip.exe — it sits in the system tray (no window). The tray icon shows the active layout (EN/RU/UK).
  2. Select the text you typed in the wrong layout.
  3. Press Ctrl+Shift+T — it's replaced in place.

Right-click the tray icon for the menu: it shows the flip hotkey, a Start with Windows toggle, and Exit. CyrFlip runs in your session (it isn't a Windows service), so autostart is a per-user startup entry.

Features

  • Global hotkey (default Ctrl+Shift+T) — works in every app.
  • Bidirectional QWERTY ↔ ЙЦУКЕН, auto-detecting direction.
  • Layout indicator built into the mouse cursor.
  • Single .exe, nothing to install — runs on stock Windows 10/11.
  • Under 50 MB of memory at rest.

Install

Via winget (once published):

winget install SerZhyAle.CyrFlip

Or download the portable ZIP from the Releases page, extract anywhere, and run CyrFlip.exe.
