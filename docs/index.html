Это фоновая утилита для Windows для тех, кто переключается между латиницей и кириллицей. Она живёт в области уведомлений: показывает активную раскладку у мигающей каретки и может исправить выделенный текст между QWERTY и ЙЦУКЕН.

This is a background Windows utility for people who switch between Latin and Cyrillic layouts. It lives in the notification area, shows the active layout next to the blinking caret, and can fix selected text between QWERTY and ЙЦУКЕН.

Це фонова утиліта для Windows для тих, хто перемикається між латиницею та кирилицею. Вона працює в області сповіщень, показує активну розкладку біля миготливої каретки й може виправити виділений текст між QWERTY та ЙЦУКЕН.

01Все возможности и настройкиFeatures and settingsМожливості та налаштування
  • Маркер EN/RU/UK у каретки, на текстовом курсоре и значке в трее; переключатель точечного стиля и индикатор CapsLock.
  • Транслитерация QWERTY ↔ ЙЦУКЕН и смена регистра; горячие клавиши настраиваются из трея без перезапуска.
  • Автозапуск для текущего пользователя, без службы Windows.
  • Необязательная история буфера: закрепление и удаление записей, пауза захвата, локальное шифрование Windows DPAPI.
  • EN/RU/UK marker at the caret, text cursor, and tray icon; dot-style toggle and CapsLock indicator.
  • QWERTY ↔ ЙЦУКЕН transliteration and case flip; hotkeys can be changed from the tray without restart.
  • Per-user autostart, not a Windows service.
  • Optional clipboard history: pin and delete items, pause capture, and Windows DPAPI local encryption.
  • Маркер EN/RU/UK біля каретки, на текстовому курсорі та значку в треї; перемикач точкового стилю та індикатор CapsLock.
  • Транслітерація QWERTY ↔ ЙЦУКЕН і зміна регістру; гарячі клавіші змінюються з трея без перезапуску.
  • Автозапуск для поточного користувача, а не служба Windows.
  • Необов’язкова історія буфера: закріплення й видалення записів, пауза захоплення, локальне шифрування Windows DPAPI.

Некоторые терминалы и приложения с собственной кареткой не сообщают её положение Windows — в них маркер у каретки может не появиться. В VS Code внешний оверлей может быть неточным; для точной метки в редакторе есть дополнительное расширение VS Code.

Some terminals and apps with a custom caret do not expose its position to Windows, so the caret marker may not appear there. In VS Code the external overlay can be imprecise; a companion VS Code extension provides an exact editor marker.

Деякі термінали й застосунки з власною кареткою не повідомляють її положення Windows, тому маркер біля каретки може там не з’явитися. У VS Code зовнішній оверлей може бути неточним; додаткове розширення VS Code дає точний маркер у редакторі.

Если принудительно завершить CyrFlip, системный I-beam может остаться изменённым до повторного запуска CyrFlip или нового входа в Windows. Не запускайте portable ZIP прямо из временной папки: сначала распакуйте его в постоянное место.

If CyrFlip is force-killed, the system I-beam can remain changed until CyrFlip runs again or you sign in again. Do not run the portable ZIP from a temporary folder: extract it to a permanent place first.

Якщо примусово завершити CyrFlip, системний I-beam може лишитися зміненим до повторного запуску CyrFlip або нового входу в Windows. Не запускайте portable ZIP із тимчасової папки: спершу розпакуйте його в постійне місце.

Горячая клавиша использует глобальный хук клавиатуры; при перевороте выделения приложение временно использует буфер обмена и восстанавливает прежнее содержимое. Эти операции выполняются локально. Исходный код, лицензия MIT, полный privacy note и история изменений доступны по ссылкам ниже.

The hotkey uses a global keyboard hook; when flipping a selection, the app temporarily uses the clipboard and restores its previous contents. These operations happen locally. Source code, MIT licence, the full privacy note, and release history are available below.

Дополнительное расширение читает код раскладки, который публикует CyrFlip, и рисует маркер прямо у каретки редактора VS Code. Для работы основное приложение должно быть запущено; webviews, терминал и другие не-редакторские панели не поддерживают decorations.

The companion extension reads the layout code published by CyrFlip and draws a marker directly at the VS Code editor caret. The main application must be running; webviews, the terminal, and other non-editor panels cannot host decorations.

Додаткове розширення читає код розкладки, який публікує CyrFlip, і малює маркер прямо біля каретки редактора VS Code. Основний застосунок має бути запущений; webviews, термінал та інші не-редакторські панелі не підтримують decorations.
