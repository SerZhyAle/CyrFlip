2. 监听全局快捷键

所有快捷键的总开关。关闭后，CyrFlip 不会拦截任何组合键——按键将照常传递给应用。

你的快捷键
3. 把快捷键让给远程桌面（mstsc/msrdc）

当远程桌面客户端窗口（mstsc/msrdc）处于前台时，CyrFlip 不拦截快捷键——按键会传到远程会话，由那台机器上的 CyrFlip 处理。如果两端都运行本程序，请启用此项。

你的快捷键
4. 全部重置...

把快捷键及其开关恢复为 CyrFlip 出厂时的状态。模块、表格行和方案不会被删除或关闭。
