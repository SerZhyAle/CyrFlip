指示器

用途

帮助你在输入前看清当前键盘布局的选项。

使用顺序

设置立即生效，无须按固定顺序操作；请使用以下分组。

界面元素

1. 在鼠标文本光标上显示布局

将标准的 I 形文本光标替换为带有小语言标记的光标。普通鼠标箭头保持不变。

你的快捷键
2. 在文本插入点旁显示布局标记

在输入框中闪烁的插入点旁绘制一个小标记。适用于向 Windows 报告插入点位置的应用。

你的快捷键
3. 用小圆点代替语言字母

在插入点旁显示一个紧凑的彩色圆点，而不是语言字母——如果字母让你分心，这很方便。

你的快捷键
4. 标记大小：

选择或输入旁边标签所指的值。继续前请检查。

你的快捷键
