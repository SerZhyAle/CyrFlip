Знімки екрана

Для чого це вікно

Знімки області або всього екрана, з малюванням поверх за бажанням; усе залишається на цьому комп'ютері.

Порядок дій

Налаштування застосовуються одразу. Обов’язкового порядку немає; користуйтеся групами нижче.
