Idiomas do Windows

Para que serve

Layouts de teclado, sua ordem e os atalhos de troca: o que antes fazia o painel «Idioma e região» do Windows.

Ordem de utilização

As definições são aplicadas de imediato. Não existe uma ordem obrigatória; use os grupos abaixo.
