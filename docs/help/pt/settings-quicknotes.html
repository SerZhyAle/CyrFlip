Notas rápidas

Para que serve

Um pequeno bloco de notas local: abra com um atalho, jogue lá um trecho de código ou uma ideia, feche.

Ordem de utilização

As definições são aplicadas de imediato. Não existe uma ordem obrigatória; use os grupos abaixo.
