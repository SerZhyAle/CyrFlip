## What this repository must keep true

- **Rules 1-5** - the token: `Hotkey.Display` / `Hotkey.TryParse`, `MouseChord.Token` / `MouseChord.TryParse`,
  `Hotkey.NameForVk`; stored chords re-written canonically (`AppConfig.ReadHotkey`, `AppConfig.CanonicalizeChord`).
  Rule 3: an unknown token or a second trigger makes the chord inert - only the fixed settings fall back to
  their default.
- **Section 6 rung 1** - `tests/CyrFlip.Tests/Fixtures/InputChord/chord-tokens.jsonl`, generated by
  `InputChordContractTests` (`CYRFLIP_WRITE_CHORD_VECTORS=1`) and copied byte for byte to the catalog.
- **Rules 6-7** - the refusals: `HotkeyRules.Check`, AltGr refused in `ChordMatcher.Matches`.
- **Rules 8-9** - one owner per chord and exact matching: `ChordRegistry`, `ChordMatcher.Matches`,
  `MouseChord.Matches`.
- **Rules 10-15** - the global hooks: `ChordMatcher`, `MouseHook`, `KeyInjection`, `KeyboardHook.Reinstall` /
  `SuspendChords`, `DeferToRemoteDesktop`.

A change to any of these is a change to the contract first: CyrFlip owns it, so the owner amends it in the
catalog (a dated section, a version) and then the code follows.
