Privacy Policy

Last updated: 18 July 2026

CyrFlip does not collect, store, log, or transmit any personal data. It runs entirely on your own device. It has no servers, makes no network requests, and contains no telemetry, analytics, advertising, tracking, or user accounts. The developer receives no data about you or your use of the app.

What the app accesses, and why

  • Keyboard. CyrFlip installs a global keyboard hook for two purposes only: to detect its activation hotkey (default Ctrl+Shift+F12) and to read the currently active keyboard layout (EN / RU / UK) so it can show the on-screen indicator. It does not record, log, store, or transmit your keystrokes. It is not a keylogger.
  • Clipboard. When you press the hotkey to transliterate a selection, CyrFlip temporarily reads the selected text (via a synthesized copy), converts it between layouts, and pastes the result back, then restores your previous clipboard contents. This happens locally and only at the moment you trigger it. Nothing from the clipboard is sent or shared.
  • Optional clipboard history. Clipboard history is off by default. If you explicitly enable it, CyrFlip stores captured Unicode text locally so you can reopen it later. The history is encrypted with Windows DPAPI for the current Windows user; it can be paused, cleared, or disabled at any time from CyrFlip. CyrFlip never sends this history anywhere.
  • Active-window / layout info. The app reads which window is focused and its keyboard layout to position and update the indicator. This information is used in memory only and is never stored or transmitted.

Local files CyrFlip writes

  • Layout file. CyrFlip writes the current layout code - a two-letter value such as EN, RU, or UK - to a small local file (%LOCALAPPDATA%\CyrFlip\layout.txt, or %ProgramData%\CyrFlip\layout.txt in the Microsoft Store version) so the optional companion VS Code extension can display the marker at the editor caret. This file contains no personal data and never leaves your device.
  • Configuration and history. Settings are stored in HKCU\Software\CyrFlip. When enabled, clipboard history is stored locally in the CyrFlip application-data folder in DPAPI-protected form. A legacy config.json may be read once during migration. None of these data leave your device.

Data sharing

None. CyrFlip does not share any data with the developer or any third party, because it does not collect or transmit any data in the first place.

Children's privacy

CyrFlip does not collect any data from anyone, including children.

Open source

CyrFlip is open source. You can review exactly what it does in the source code at github.com/SerZhyAle/CyrFlip.
