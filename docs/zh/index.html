Windows · 通知区域小工具

修正用错误布局输入的文本，并在开始输入前就看清当前布局。

CyrFlip 在文本插入点旁显示当前布局的代码，并直接替换输错的文本，无需重打。

这款 Windows 后台小工具会在插入点旁显示当前布局，可一键安装 13 种常用语言，并在你选定的布局之间创建任意多的转换配对。

ghbdtn→ Ctrl+Shift+F12 →привет
Microsoft Store GitHub Releases
winget install SerZhyAle.CyrFlip
  1. 从 Microsoft Store 安装、使用 winget 安装，或把 GitHub Releases 的 ZIP 解压到一个固定文件夹。
  2. 运行 CyrFlip.exe，在通知区域找到它的图标。
  3. 选中输错的文本并按 Ctrl+Shift+F12。

输入前先看清布局

插入点旁会出现两个字母的标记；13 种精选语言各有自己的颜色，开启 CapsLock 时标记还会加上边框。

修正已经打好的句子

选中形如 ghbdtn 的文本，按 Ctrl+Shift+F12。

修正误按的 CapsLock

选中文本，用另一个可自定义的快捷键交换大小写。

自定义布局配对

一张转换表：可添加任意多的配对，每对都有自己的快捷键，并且双向有效。

快速启动

可选：把你的程序、脚本和 yt-dlp 下载做成方案，从托盘、专属快捷键或任务栏跳转列表运行。默认关闭。

翻译选中的文本

可选：选中文本并按 Ctrl+Shift+F9，译文会在鼠标指针旁的小窗口里边生成边出现；目标语言可以按行添加，每行有自己的快捷键。翻译由需要你另行安装的免费程序 Ollama 在你自己的电脑上完成，文本不会发送到任何云服务。默认关闭。

需要知道

需要 Windows 10/11 x64。转换按按键的物理位置进行；已经由输入法合成的文本（例如中文拼音）会保持不变。在部分自绘光标的终端和应用中标记可能不出现——此时托盘图标和鼠标光标仍会显示当前布局。
