为什么 Windows 或杀毒软件可能对 CyrFlip 发出警告

最后更新：2026 年 9 月 24 日 · English（原文）

本页针对的是 Windows 或你的杀毒软件刚刚拦下 CyrFlip 的那一刻。它依次说明：这是什么警告、为什么会出现、 具体该点击什么，以及 CyrFlip 从不做什么 - 按这个顺序，方便你自己做决定。

这是什么警告

“Windows 已保护你的电脑”

这是 Microsoft Defender SmartScreen。蓝色窗口写着："Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk."（译文：Microsoft Defender SmartScreen 阻止了一个无法识别的应用启动，运行此应用可能会给你的电脑带来风险。） 点击更多信息后，它会显示 App: CyrFlip.exe 和 Publisher: Unknown publisher（译文：发布者未知），并提供仍要运行和不运行两个按钮。

杀毒软件隔离或阻止了 CyrFlip.exe

目前报告过的情况是 Avast / AVG，它将其命名为 IDP.Generic（Behavior Shield）。 其他杀毒软件可能会用别的名称来称呼同一类检测。

会在哪里遇到：GitHub 上的 ZIP 和 winget 软件包（winget 安装的正是同一个 ZIP） 可能会出现这些警告。Microsoft Store 版本由 Microsoft 签名，不会出现 SmartScreen 警告。

为什么会出现

CyrFlip 免费、开源，由一位独立开发者制作。ZIP 包没有代码签名：代码签名证书每年都要花钱， 不购买是有意的选择。SmartScreen 根据文件的信誉来决定是否信任它 - 也就是有多少人运行过这个完全相同的文件 - 因此一个新的、未签名的版本起初毫无信誉，随着下载的人越来越多，警告会逐渐消失。

还有第二个原因，签名也无法消除。为了完成本职工作，布局指示器所做的恰恰是杀毒软件行为启发式规则所盯着的事： 它安装全局键盘钩子（上下文菜单开启时还有鼠标钩子），模拟 Ctrl+C 和 Ctrl+V，读取剪贴板，并且可以替换系统的文本光标。直接从临时文件夹（ZIP 内部，或 %TEMP%）运行程序，又会多一个信誉方面的疑点。

警告只是在面对一个它不认识的文件时尽职而已。下面的事实可以让你自己判断这个文件。

具体该点击什么

  1. 先把 ZIP 解压到一个固定的文件夹，例如 %LOCALAPPDATA%\Programs\CyrFlip\， 然后从那里启动 CyrFlip.exe - 不要在压缩包内部直接运行。
  2. SmartScreen：点击更多信息，确认应用是 CyrFlip.exe， 然后点击仍要运行。Windows 会针对这个文件记住你的选择。
  3. 杀毒软件隔离：从隔离区恢复该文件，并只为那一个文件夹添加例外。 然后向你的杀毒软件厂商报告误报（Avast 和 AVG 的网站上都有误报提交表单），这会帮助其他所有用户。
  4. 可选的核对：将文件的 SHA-256 与 发布页面上 ZIP 旁边公布的 .sha256 文件进行比对（在 PowerShell 中运行 Get-FileHash CyrFlip.exe）， 或者把文件上传到 VirusTotal。
  5. 或者干脆避开警告：从 Microsoft Store 安装 CyrFlip， 那里的版本由 Microsoft 签名。

这里没有任何一步要求你为整台电脑关闭某项保护 - 只涉及一个文件、一个文件夹，而且两者都可以撤销。

CyrFlip 从不做的事

  • 从不为自己请求管理员权限。它以你的普通用户权限运行。
  • 从不记录、保存或发送你的按键。键盘钩子只用于识别 CyrFlip 自己的快捷键。
  • 从不向任何地方发送任何内容 - 没有遥测，没有账户，也没有自己的服务器。 唯一的例外是可选的翻译功能（默认关闭）：它会把选中的文本发送到你设置的 Ollama 地址，默认是你自己电脑上的一个程序。
  • 从不安装服务或驱动程序。
  • 从不在你的用户配置文件之外写入，唯一的例外是 Microsoft Store 版本中 %ProgramData%\CyrFlip 下那个小布局文件的一份副本，它是为旧版 VS Code 扩展保留的。
  • 从不随 Windows 启动，除非你勾选了该选项。

你仍可能看到的管理员提示

  • 你标记为以管理员身份运行的快速启动方案：该提示针对的是你的程序，而不是 CyrFlip。 在方案中取消勾选该选项，提示就不会再出现。
  • 便携版中的安装 Ollama：CyrFlip 会下载 Ollama 的官方安装程序并启动它； 出现的任何提示都来自 Ollama 安装程序本身。

它会更改什么，以及如何撤销

  • 随 Windows 启动 - 在 CyrFlip 的设置中取消勾选该选项。
  • 文本光标（默认关闭）- CyrFlip 退出时会恢复标准光标。
  • Windows 输入设置（键盘布局、切换快捷键），仅当你在Windows 语言选项卡中更改它们时 - 该选项卡的恢复按钮会还原你原来的状态。
  • 它自己的设置和数据 - 注册表项 HKCU\Software\CyrFlip 以及文件夹 %LOCALAPPDATA%\CyrFlip 和 %APPDATA%\CyrFlip。退出 CyrFlip 后删除它们， 就不会留下任何痕迹。

同样的事实在隐私政策中有更详细的说明。
