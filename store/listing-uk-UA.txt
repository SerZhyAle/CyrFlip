========================================
CyrFlip — лістинг Microsoft Store (uk-UA)
========================================

КОРОТКИЙ ОПИС (max 270 символів)
----------------------------------
Виправляйте текст, набраний не в тій розкладці (EN ↔ RU/ЙЦУКЕН), однією гарячою клавішею, і завжди бачте активну розкладку прямо біля курсору.


ОПИС
----
CyrFlip — крихітна фонова утиліта для Windows, що вирішує дві типові проблеми при роботі з латинською та кириличною клавіатурами.

ЖИВИЙ ІНДИКАТОР РОЗКЛАДКИ
CyrFlip замінює системний текстовий курсор курсором із міткою активної розкладки (EN / RU / UK) і показує маленький маркер прямо поруч із миготливим курсором введення — так ви завжди знаєте, в якій розкладці друкуєте, не дивлячись на клавіатуру чи панель задач.

МИТТЄВЕ ВИПРАВЛЕННЯ РОЗКЛАДКИ
Набрали "зне с'ш" замість "the euro"? Виділіть зіпсований текст, натисніть Ctrl+Shift+F12 — і він виправиться прямо на місці, в будь-якому додатку. Працює в браузерах, текстових редакторах, месенджерах, IDE та інших програмах.

КЛЮЧОВІ МОЖЛИВОСТІ
• Підтримка розкладок EN, RU та UK
• Курсор з індикатором та маркер біля точки введення — завжди видно там, де ви пишете
• Транслітерація виділеного тексту QWERTY ↔ ЙЦУКЕН однією гарячою клавішею
• Працює в системному треї, налаштування не потрібні
• Один portable .exe файл — не потребує встановлення та середовища виконання
• Без реклами, стеження, хмари та облікових записів
• Гаряча клавіша та розмір курсору налаштовуються через простий файл конфігурації
• Сумісний з Windows 10 та Windows 11
• Відкритий вихідний код (MIT)


КЛЮЧОВІ СЛОВА
-------------
розкладка клавіатури, транслітерація, кирилиця, qwerty, йцукен, індикатор розкладки, зміна розкладки


СИСТЕМНІ ВИМОГИ
---------------
(Внести до Partner Center → Властивості → Системні вимоги.)

Мінімум: Windows 10 (збірка 17763 / версія 1809) або Windows 11, x64.
.NET Framework 4.8 попередньо встановлено на всіх підтримуваних версіях Windows — нічого додатково встановлювати не потрібно.

НЕ ПОТРІБНО: Visual Studio Code. Розширення для VS Code — повністю необов'язковий супутник
для користувачів VS Code, яким потрібна точна мітка розкладки біля каретки редактора Monaco.
CyrFlip працює повністю без VS Code: значок у треї, маркер на курсорі миші, оверлей біля каретки
та гаряча клавіша транслітерації — все це доступно в будь-якому застосунку без VS Code.
