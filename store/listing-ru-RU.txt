========================================
CyrFlip — листинг Microsoft Store (ru-RU)
========================================

КРАТКОЕ ОПИСАНИЕ (max 270 символов)
-------------------------------------
Исправляйте текст, набранный не в той раскладке (EN ↔ RU/ЙЦУКЕН), одной горячей клавишей, и всегда видьте активную раскладку прямо у курсора.


ОПИСАНИЕ
--------
CyrFlip — крошечная фоновая утилита для Windows, которая решает две типичные проблемы при работе с латинской и кириллической клавиатурами.

ЖИВОЙ ИНДИКАТОР РАСКЛАДКИ
CyrFlip заменяет системный текстовый курсор курсором с меткой активной раскладки (EN / RU / UK) и отображает маленький маркер прямо рядом с мигающим курсором ввода — так вы всегда знаете, в какой раскладке печатаете, не глядя на клавиатуру или панель задач.

МГНОВЕННОЕ ИСПРАВЛЕНИЕ РАСКЛАДКИ
Набрали "пше ещпу" вместо "the euro"? Выделите испорченный текст, нажмите Ctrl+Shift+F12 — и он исправится прямо на месте, в любом приложении. Работает в браузерах, текстовых редакторах, мессенджерах, IDE и других программах.

КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ
• Поддержка раскладок EN, RU и UK
• Курсор с индикатором и маркер у точки ввода — всегда видны там, где вы пишете
• Транслитерация выделенного текста QWERTY ↔ ЙЦУКЕН одной горячей клавишей
• Работает в системном трее, настройки не нужны
• Один portable .exe файл — не требует установки и среды выполнения
• Без рекламы, слежки, облака и учётных записей
• Горячая клавиша и размер курсора настраиваются через простой файл конфигурации
• Совместимо с Windows 10 и Windows 11
• Открытый исходный код (MIT)


КЛЮЧЕВЫЕ СЛОВА
--------------
раскладка клавиатуры, транслитерация, кириллица, qwerty, йцукен, индикатор раскладки, смена раскладки


СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
(Внести в Partner Center → Свойства → Системные требования.)

Минимум: Windows 10 (сборка 17763 / версия 1809) или Windows 11, x64.
.NET Framework 4.8 предустановлен на всех поддерживаемых версиях Windows — ничего дополнительно устанавливать не нужно.

НЕ ТРЕБУЕТСЯ: Visual Studio Code. Расширение для VS Code — полностью необязательное дополнение
для пользователей VS Code, которым нужна точная метка раскладки у каретки редактора Monaco.
CyrFlip работает полностью без VS Code: значок в трее, маркер на курсоре мыши, оверлей у каретки
и горячая клавиша транслитерации — всё это доступно в любом приложении без VS Code.
