@@ShortDescription
托盘里的键盘与桌面工具箱：在文字光标旁实时显示布局标记，一键修正用错布局或误开 CapsLock 输入的文本，还能截取屏幕区域；另有可选的选区菜单、本地翻译器、快速笔记、剪贴板历史和快速启动。
@@Description
CyrFlip 是托盘里的键盘与桌面工具箱。开箱即用，它让你始终用对布局，并修正用错布局输入的文本；其余一切都是可选模块，需要时再开启。

用对布局输入。实时布局标记紧贴闪烁的文字光标，让你随时知道接下来会用哪种布局输入，即使在浏览器和 VS Code 的聊天框里也一样，而大多数指示器都到不了那里。同一个标记还可以替换鼠标的工字形光标，并显示在托盘图标上。13 种精选语言各有自己的颜色，其他任何 Windows 布局也会显示自己的两字母代码，开启 CapsLock 时标记周围会加上一圈细边框。

选中用错布局打出的文字，按 Ctrl+Shift+F12：CyrFlip 会就地转换，双向都可以，混排文本同样有效。“从这个布局到那个布局”的配对想加多少就加多少，每组都有自己的快捷键；文本按物理按键位置转换，因此 AZERTY 和 QWERTZ 都能正确处理。另一个快捷键修正误开的 CapsLock。“Windows 语言”选项卡可以安装、重新排序和移除键盘布局（不会下载任何东西，它们本就随 Windows 提供），并指定由 Windows 自身处理的按语言快捷键，因此即使 CyrFlip 已关闭，它们仍然有效。

对选中内容直接操作。按住 Ctrl 右键点击选区，CyrFlip 自己的菜单就会在指针处打开：复制、剪切和粘贴，你的布局转换，大小写修正，翻译，快速启动和剪贴板历史；它不会抢走焦点，因此选区仍然保留。一个键盘组合键也能在文字光标处打开同一个菜单。默认关闭。 可选的符号窗口按名称、关键词或 Unicode 代码找到键盘上没有的字符，点击即复制。

内置翻译器同样是可选的。在 Windows 的任何地方选中文本，按下它的快捷键，翻译就会出现在鼠标指针旁的小窗口里，随着模型书写逐字填充。它运行在 Ollama 上，这是一个你在自己电脑上安装一次的免费程序：CyrFlip 不捆绑它，没有账号也没有密钥，默认只与 http://localhost:11434 通信，也就是你自己的机器。翻译方向是一张开放的表，每个方向都有自己的快捷键；结果可以复制到剪贴板，也可以直接粘贴覆盖所选内容。默认模型是 aya-expanse:8b（约 4.7 GB）。也要说清楚：质量取决于本地模型，冷启动后的第一次翻译需要等一会儿，模型占用的内存属于 Ollama 进程，而不是 CyrFlip。

留住复制和写下的内容。可选的剪贴板历史把最近的文本保存在本地，可在独立窗口中搜索；条目可以置顶、删除、暂停或清空，每条记录都以 Windows DPAPI 针对你的 Windows 账户加密。可选的快速笔记用 Ctrl+Shift+Alt+N 打开，文本原样保存，没有 Markdown，也没有自动格式化，因此代码片段贴回去时一字不改；搜索会查找每一条笔记的内容，笔记在磁盘上同样加密。笔记和剪贴板历史可以通过一个纯文本文件迁移到另一台电脑或手机，导出和导入都由你自己完成。可选的、位于你自己的交换服务器上的剪贴板，会把一段复制的文本、一张图片或一个文件传到你的其他设备，先在你的电脑上加密，并且仅在你按下按钮时才传送。

启动与截图。按 Ctrl+PrintScreen，屏幕会定格，你拖出一个区域，图片就进入剪贴板，也可以选择同时以 PNG 保存到文件夹。快速启动是一个可选模块，它把你的程序、脚本和 yt-dlp 下载变成场景，可从托盘、各自的快捷键或任务栏跳转列表启动；独立工具 OneClickRunner 的场景可以导入，且不会改动原文件。两个防休眠开关让 Windows 在你工作时不睡眠、不熄屏。

只属于你。可选模块在你开启前保持关闭，每个快捷键都能单独关闭，CyrFlip 还可以把快捷键让给位于前台的远程桌面窗口。界面提供 13 种语言，包含从右向左书写的语言，主题可选浅色、深色或跟随 Windows。它常驻系统托盘，占用内存很少，在 Windows 10/11 上无需额外安装任何东西。 所有快捷键连同其状态集中在设置的同一个列表中，任何一个都可恢复默认。

隐私：CyrFlip 使用键盘钩子仅用于识别它自己的快捷键，使用剪贴板仅用于执行你触发的操作；只有在你开启了可选的上下文菜单时，它才会使用鼠标钩子，而且仅用于识别打开该菜单的那一个鼠标组合。它不记录按键，除非你启用两项可选功能之一，否则不会打开任何网络连接：一是翻译器，它只与你指定的 Ollama 服务器通信 —— 默认就是你自己的电脑；二是你自己的交换服务器上的剪贴板，它会把剪贴板中的内容在你的电脑上加密、供你自己的设备使用，发送到你已登录的服务器，且仅在你按下它的按钮时才发送。如果出了问题，设置窗口会把 CyrFlip 的日志打包成一个压缩包，并打开一封已附加该文件的给作者的邮件。邮件由您自己发送，剪贴板历史绝不会进入压缩包。 开源：https://github.com/SerZhyAle/CyrFlip

首次启动时，五步欢迎导览会介绍 CyrFlip，并提供打开常规设置进行初始配置的选项。跳过或关闭即可保留默认值。更新后不会再次自动显示；可从关于页面重新查看。随 Windows 启动保持关闭，直到您主动选择。

在“常规”页面将 CyrFlip 设置导出为 JSON，导入前预览更改，或恢复上次导入前的设置。最近三个快照保存在本地。文件不包含笔记、剪贴板历史、启动方案、本机路径或 Windows 系统设置。启用记录或使用其他翻译服务器需要单独同意。
