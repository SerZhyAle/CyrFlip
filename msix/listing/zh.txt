@@ShortDescription
在文字光标旁实时显示键盘布局，并可一键在任意两种已安装布局之间转换文本。
@@Description
CyrFlip 是一款小巧的 Windows 托盘应用：它在你打字的地方直接显示当前键盘布局，并能一键在不同布局之间转换文本。

它的核心功能是紧贴闪烁文字光标的实时布局标记，让你随时知道接下来会用哪种布局输入 —— 即使在浏览器和 VS Code 的聊天框里也一样，而大多数指示器都到不了那里。同一个标记还可以替换鼠标的工字形光标，并显示在托盘图标上。13 种精选语言各有自己的颜色，其他任何 Windows 布局也会得到属于自己的两字母代码，开启大写锁定时标记周围会加上一圈细边框。

选中用错布局打出的文字，按下快捷键：CyrFlip 会就地在 QWERTY 与 ЙЦУКЕН 之间转写，双向都可以，混排文本同样有效。另一个可自定义的快捷键用同样的方式修正不小心开着的大写锁定。

需要其他语言？建一张布局转换表：想要多少组“从这个布局到那个布局”都行，每组都有自己的全局快捷键。文本按物理按键位置转换，因此 AZERTY 和 QWERTZ 布局都能正确处理，而且每一组都是双向的 —— 当该组的另一种布局处于活动状态时再按同一组合键，文本就会转换回去。

设置窗口还替代了 Windows 的语言面板：安装、重新排序和移除键盘布局（不会下载任何东西 —— 它们本就随 Windows 提供），选择循环切换语言的快捷键，并指定由 Windows 自身处理的按语言直达快捷键，因此即使 CyrFlip 已关闭它们仍然有效。这两部分都会为你此前的状态保留一份一次性备份。

剪贴板历史是可选的，默认关闭。启用后，它会把最近的 Unicode 文本保存在本地，可在独立窗口中搜索；条目可以置顶、删除、暂停或清空，并以 Windows DPAPI 加密保护当前 Windows 用户的数据。

快速启动是第二个可选模块，同样在你启用之前保持关闭。它把你的程序、脚本和 yt-dlp 下载变成一个个场景，你可以从托盘子菜单、从各自的全局快捷键，或者从任务栏跳转列表启动 —— 只要固定到任务栏，即使 CyrFlip 没有运行也能启动。本模块吸收了独立工具 OneClickRunner，其中的场景可在首次运行时导入，且不会改动原文件。

内置翻译器同样是可选的，在你启用之前保持关闭。在 Windows 的任何地方选中文本，按下它的快捷键，翻译就会出现在鼠标指针旁的小窗口里，随着模型书写逐字填充。它运行在 Ollama 上 —— 一个你在自己电脑上安装一次的免费程序：CyrFlip 不捆绑它，没有账号也没有密钥，默认只与 http://localhost:11434 通信，也就是你自己的机器，因此不会有任何文本发送给开发者或任何云服务。翻译方向和布局转换一样是一张开放的表：每一行是一个目标语言加上自己的全局快捷键，而且一行还可以跟随界面语言，或跟随你翻译时所在窗口的活动布局的语言。结果可以放入剪贴板，可选的历史会像记录任何一次复制那样记下它，也可以直接粘贴覆盖所选内容 —— 两者默认都关闭。“翻译”选项卡可以打开 Ollama 下载页、启动服务、检查连接并下载模型：qwen2.5:3b（约 2 GB）是默认模型，gemma2:2b（约 1.6 GB）适合配置较弱的机器，aya-expanse:8b（约 5 GB）在 8 GB 及以上内存下翻译质量明显更好。也要说清楚：质量取决于本地模型；冷启动后的第一次翻译需要等待模型加载；Ollama 和模型是一次性的数 GB 下载；模型占用的内存属于 Ollama 进程，而不是 CyrFlip。超过 4000 个字符的选区只翻译到该处为止，窗口会给出提示。

每个快捷键都能单独开关；当远程桌面客户端位于前台时，CyrFlip 可以把快捷键让给它，改由远程会话中运行的那一份来处理；另有两个防休眠开关，让 Windows 在你工作时不睡眠、不熄屏。

界面提供 13 种语言，包含从右向左书写的语言。它常驻系统托盘，占用内存很少，在 Windows 10/11 上无需额外安装任何东西。

隐私：CyrFlip 使用键盘钩子和剪贴板，仅用于识别当前布局和执行你触发的操作。它不记录按键，除非你启用翻译器，否则不会打开任何网络连接；而翻译器只与你指定的 Ollama 服务器通信 —— 默认就是你自己的电脑。开源：https://github.com/SerZhyAle/CyrFlip
