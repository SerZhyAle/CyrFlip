# CyrFlip

CyrFlip — крихітна утиліта для Windows (живе в треї) з двома завданнями:

1. **Індикатор розкладки там, де ви друкуєте (головна функція).** Маленький маркер **EN / RU / UK** показується і на текстовому курсорі миші (I-beam), **і поруч із мигаючою кареткою** — щоб ви завжди бачили, у якій розкладці набираєте. Оновлюється в реальному часі. (Вказівник миші під час набору часто лишається стрілкою — тому маркер біля каретки особливо важливий.)
2. **Транслітерація однією клавішею.** Текст, набраний у неправильній розкладці, можна «перевернути» на місці між QWERTY та ЙЦУКЕН (EN ↔ RU, UK у планах) гарячою клавішею.

## Як це працює

1. CyrFlip відстежує активну розкладку й замінює системний **текстовий курсор** на каретку з маркером розкладки (EN/RU/UK). Той самий маркер показується й на значку в треї.
2. Глобальний низькорівневий хук клавіатури слухає гарячу клавішу (за замовчуванням **Ctrl+Shift+F12**); під час спрацювання виділення копіюється, транслітерується та вставляється назад.

> Зміна курсора системна (`SetSystemCursor`) і відновлюється під час виходу CyrFlip. Змінюється лише текстовий I-beam, а не звичайна стрілка-вказівник.

## Використання

- **Запуск** — запустіть `CyrFlip.exe`. Вікна немає; програма сидить в області сповіщень (системному треї). Значок показує активну розкладку (**EN/RU/UK**).
- **Виправлення тексту** — виділіть текст у неправильній розкладці, натисніть **Ctrl+Shift+F12** — і його буде замінено на місці. Працює в будь-якому застосунку (Блокнот, Word, браузери, …).
- **Меню в треї** (правий клік на значку):
  - **Flip EN ⇄ RU: Ctrl+Shift+F12** — показує поточну гарячу клавішу.
  - **Start with Windows** — запуск CyrFlip під час входу в систему (для поточного користувача, без прав адміністратора).
  - **Exit** — вихід.

CyrFlip — звичайний застосунок, а не служба Windows: глобальний хук клавіатури та індикатор розкладки мають працювати в інтерактивному сеансі користувача, тому «автозапуск» — це запис в автозавантаженні користувача, а не служба.

## Вимоги

- Windows 10 / 11 (x64)
- .NET Framework 4.8 (передвстановлений у Windows 10/11 — нічого додатково встановлювати не потрібно)

## Збірка та запуск

```powershell
dotnet build CyrFlip.sln -c Release
.\src\CyrFlip\bin\Release\net48\CyrFlip.exe
```

Запуск тестів:

```powershell
dotnet test CyrFlip.sln
```

## Конфігурація

Необов'язковий `config.json` (поруч з exe або в `%APPDATA%\CyrFlip\`):

```json
{ "hotkey": "Ctrl+Shift+F12", "cursorSize": 24 }
```

## Відомі обмеження

- **Маркер біля каретки видно не в усіх застосунках.** CyrFlip визначає позицію каретки через системну каретку Windows або UI Automation. Деякі застосунки не надають ні того, ні іншого — насамперед **вікна консолі/термінала** (Командний рядок, PowerShell, Windows Terminal) та окремі застосунки з власною відрисовкою тексту і слабкою підтримкою UI Automation. Там маркер біля каретки прихований; значок у треї та маркер на курсорі миші продовжують показувати розкладку. А в деяких редакторах (наприклад, VS Code та інші на основі Monaco) UI Automation повідомляє позицію каретки неточно, тому маркер може з'являтися біля краю поля введення, а не точно біля каретки.
- **Текстовий курсор миші (I-beam) може лишитися зміненим після примусового завершення.** CyrFlip замінює системний I-beam глобально й відновлює його під час виходу. Якщо процес завершено жорстко (наприклад, «Зняти завдання» у Диспетчері завдань), Windows не відновить курсор до наступного запуску CyrFlip або повторного входу.
- **Транслітерація лише EN ↔ RU.** Індикатор розкладки підтримує EN/RU/UK, але «переворот» гарячою клавішею наразі перетворює між QWERTY та ЙЦУКЕН; українські специфічні літери поки не транслітеруються.
- **Під час «перевороту» зберігається лише текст буфера обміну.** Зображення та файли в буфері не відновлюються.
